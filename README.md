# AST305 Project 2 — Optical spectra

Data files used in the analysis presented in
"Optical emission-line classification of two unidentified SDSS galaxies".

## Files
- spec5.fits — SDSS optical spectrum of Spec5
- spec8.fits — SDSS optical spectrum of Spec8

The spectra were analysed with SPLAT-VO for emission-line
measurements, redshift determination, and BPT diagnostics.
